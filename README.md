Concept Overview

Q1 (Networking): TCP is connection-oriented and reliable; UDP is connectionless and low-latency.
Q2 (JDBC Security): PreparedStatement uses parameterized inputs to prevent SQL injection.
Q3 (Servlets & Session): Servlets process logic; JSP renders UI. HttpSession maintains user state across requests.
Q4 (Spring DI & Microservices): Microservices decouple application components. Dependency Injection (DI) injects dependencies automatically via IoC.
Q5 (RMI): Enables remote method invocation across a client-server network using an RMI registry.
Q6 (Web Container): Manages servlet lifecycle (init, service, destroy) and request multithreading.
Q7 (MVC): Separates application data (Model/DAO), user interface (JSP), and business logic (Controller).
